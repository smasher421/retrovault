# RetroVault

A retro gaming collection manager with:
- authentication and Steam login flow
- search by title and platform
- metadata fetching through RAWG
- CRUD collection tracking
- Supabase-ready persistence

## Setup

1. Install dependencies:
   npm install
2. Copy `.env.example` to `.env` and fill in your Supabase and RAWG values.
3. Run the app:
   npm run dev:all

## Database

Create a `games` table in Supabase with these fields:

```sql
create table public.games (
  id bigint generated by default as identity primary key,
  user_id text not null,
  title text not null,
  platform text not null,
  genre text,
  year integer,
  status text default 'Backlog',
  notes text,
  cover_image text,
  created_at timestamp with time zone default now()
);
```

## Notes

The app will run in a local demo mode if Supabase environment values are not configured.
