# Apply a work tone

Read `references/tone-profile.md` for the current profile and its evidence status. User instructions and examples supplied for this task take precedence.

1. Identify audience, channel, language, and whether this is a light edit or a full rewrite. Preserve the source's intended message and degree of formality unless asked to change it.
2. When supplied with examples, infer observable features: sentence length, directness, technical vocabulary, contractions, warmth, humor, headings, and calls to action. Separate stable patterns from one document's quirks.
3. If there are no representative examples, use the provisional profile and label it provisional when describing the work. Never claim to have analyzed emails, documents, or commits that were not actually provided or authorized for reading.
4. Rewrite while keeping names, quantities, dates, links, commitments, qualifications, and uncertainty intact. Preserve intentional technical terms. Do not add opinions, biographical facts, or promises in the user's voice.
5. Compare the rewrite against the source for meaning and the profile for style. Return the edited text first. Add notes only when a factual ambiguity, meaningful assumption, or requested explanation warrants them.

When asked to distill or update the profile, record general style rules and short synthetic examples; avoid storing private message excerpts, account identifiers, or confidential work details in the skill. Ask for representative samples only when needed for a closer match. Reading an unrelated inbox is not a prerequisite for a useful rewrite.

Keep tone adaptation distinct from publication: do not send or publish the result unless authorized separately.
